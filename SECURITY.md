# Security boundary

Somolier is fail-closed by design.

- Do not execute payloads during WIFF.
- Treat SWIRL as a quarantine/sealing boundary; the v0.1 reference function is only a placeholder and is not cryptographic protection.
- TASTE does not decide truth or authority.
- Unregistered Deciders SPIT everything.
- SWALLOW requires all configured gates to pass.
- SPIT should preserve evidence according to the caller's retention policy.
